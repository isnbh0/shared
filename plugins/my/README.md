# my

An incubator and sandbox for skills and macros I keep returning to in real work.

The skills are portable and can be installed individually. Most activate only when requested by name; `tractatus` can also be selected for a matching document task, and `video-knowhow` is selected when making or reviewing video made with code. `spex` requires the separate spex plugin for its implementation workflow. Its recovery guidance explains how to continue if that dependency is missing. If doctype is installed too, select the `tractatus` skill from the intended plugin.

| Skill | Purpose |
| --- | --- |
| `principles` | Apply working principles for building projects to implementation, design, and review. |
| `spex` | Implement an existing spex specification with coordinated work and rigorous verification. |
| `grounding` | Pursue the foundation you wish the work had started from and make invalid states impossible to express. |
| `layout-grounding` | Preserve grouping and reading order with stable interface anchors and natural content flow. |
| `aspects` | Design overlapping concerns with explicit scope and composition. |
| `space-race` | Coordinate partially dependent work in parallel. |
| `tightloop` | Match verification cost to the reach of a change. |
| `editorial-ko` | Apply Korean editorial standards. |
| `editorial-standards` | Apply English editorial standards. |
| `hemingway` | Write plainly and concretely. |
| `slow-down` | Restate the previous response with its jargon, initialisms, and references explained. |
| `proofread-ko` | Proofread Korean text in repeated independent cold passes. |
| `gauntlet` | Collect intuitive judgments through a fast, blinded A/B choice page built from the person's own material. |
| `design-feedback` | Build a local HTML design gallery with per-frame comments, screenshots, and a feedback ZIP that round-trips between revisions. |
| `findable` | Keep project conventions reachable from agent entry points. |
| `debrief-manifesto` | Report work from the reader's point of view. |
| `deputy` | Own authorized work through verified completion. |
| `visual-grounding` | Build visual systems from semantic structure and inspect the result. |
| `tractatus` | Write and render a navigable outline page with the bundled renderer. |
| `simple-now` | Make the useful simple change and leave a robust follow-up. |
| `complexity-panel` | Convene cold, read-only reviewers to map accidental complexity and rank cleanup. |
| `video-knowhow` | Consult bundled practice notes, a starter, and a showcase for video made with code. The `kb/` folder is generated from its source repository. |
| `codex-image-gen` | Generate new images through authenticated Codex with a bundled runner, verified original bytes, and recovery without regeneration. |
