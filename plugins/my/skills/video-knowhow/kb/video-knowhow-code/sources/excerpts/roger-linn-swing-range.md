# Roger Linn — the useful swing range

- **Source:** Roger Linn, interview with Attack Magazine ("Swing, Groove and the Magic of MPC Timing").
- **URL:** https://www.attackmagazine.com/features/interview/roger-linn-swing-groove-magic-mpc-timing/
- **Checked:** 2026-10-14.

## The passage

"Between 50% and around 70% are lots of wonderful little settings." In Linn's framing, 50% swing is straight (no delay on the off-sixteenths), 54–58% is light shuffle, 58–62% is medium shuffle, 62–66% is a triplet feel, and beyond about 75% the late notes begin to overlap the next beat.

## Where it is relied on

[Groove and feel](../../knowledge/Groove%20and%20feel.md) uses the 50–70% band as the frame for its swing case values (SLASH_MY's swung sections run 0.54–0.61: exec, nav, and reveal at 0.54, writing drifting 0.57 → 0.61). It treats each position inside the band as a production choice to audition, with no position ranked above another. The [Soundtrack code case](../../cases/Soundtrack%20code.md) cites the same range in its table of SLASH_MY's swing values per section.
