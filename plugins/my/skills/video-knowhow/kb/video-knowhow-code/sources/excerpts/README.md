# Excerpts of relied-on external sources

Short copies of the source passages the package relies on, one file per claim. Each file gives the source, its URL, the date the passage was checked, the passage itself, and the pages that rely on it. A page that relies on a passage links its copy here next to the live web source, so the text stays available when a link dies. The source status of each audio claim is in the [audio source ledger](../Audio%20sources.md).

- [IBM layout and the reading path](ibm-layout-reading-path.md): IBM Design Language on entry points, the reading path, the 2x Grid, and white space.
- [JP-8000 supersaw](jp8000-supersaw-szabo.md): Szabo's 2010 measurements of the supersaw's detune offsets, random phases, and high-pass.
- [Karplus–Strong](karplus-strong-patent.md): the plucked-string algorithm and the decay stretching in its 1983 patent.
- [Microtiming studies](microtiming-danielsen-hennig.md): Danielsen's laid-back snares, Hennig's correlated deviations, and Friberg and Sundberg's timing JND.
- [PolyBLEP](polyblep-valimaki.md): Välimäki's polynomial correction of a saw's jump.
- [Porter and Duff compositing](porter-duff-compositing.md): the 1984 paper behind compositing separately rendered elements.
- [Roger Linn on swing](roger-linn-swing-range.md): the 50–70% useful swing range.
- [SMIL 1.0 time groups](smil-time-groups.md): sequential and parallel time groups on a shared clock.
- [SVG 1.1 animation](svg-animation-elements.md): the animation elements, interval pacing, and motion paths.
- [TR-808 cymbal oscillators](tr808-cymbal-oscillators.md): the six shared oscillators and their factory frequencies.
- [WCAG 2.3.1 flash thresholds](wcag-231-flash-thresholds.md): the three-flash rule and the general and red flash thresholds.
