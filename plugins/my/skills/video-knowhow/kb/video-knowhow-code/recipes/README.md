# Recipes with working examples

A recipe adds no new capability to learn. It combines [operations](../Operations.md) into one useful arrangement of sources, time, layout, and rendering. Swap any ingredient for new material that does the same job. Each linked example shows a real output or a live scene, and the code that produced it.

| Recipe | What the viewer sees | Working evidence |
| --- | --- | --- |
| [Event announcement opener](Event%20announcement%20opener.md) | A title, speaker, photograph, time, place, and event identity appear in a short branded sequence. | Shortvid's [published MP4](https://user-images.githubusercontent.com/6263857/214966765-a22cc958-95bb-49fc-9ea9-3a4ef1392fae.mp4) and [composition source](https://github.com/lyonjs/shortvid.io/blob/main/remotion/compositions/templates/talks/talk/branded/TalkBranded.tsx). |
| [Diagram explainer](Diagram%20explainer.md) | A moving point on a circle shows how its vertical position traces a sine wave. | Manim's [rendered MP4](https://docs.manim.community/en/stable/SineCurveUnitCircle-1.mp4) and [example source](https://docs.manim.community/en/stable/examples.html#sinecurveunitcircle). |
| [Animated data comparison](Animated%20data%20comparison.md) | Three labeled bars grow to their values in sequence, with one comparison highlighted. | Remotion's [rendered MP4](https://remotion.media/elements/data-vertical-bar-chart-preview.mp4) and [source with preview](https://www.remotion.dev/elements/data/vertical-bar-chart/). |
| [Procedural 3D scene](Procedural%203D%20scene.md) | A moving object sits in a lit ocean and sky scene whose surfaces change over time. | The official [live three.js scene](https://threejs.org/examples/webgl_shaders_ocean.html) and [source](https://github.com/mrdoob/three.js/blob/dev/examples/webgl_shaders_ocean.html). This example proves the moving scene; frame capture for a video is a separate operation. |

The first three examples come with published video files. The fourth is a working scene rendered in the browser. Each page keeps what was observed in the example apart from the suggested adaptation. For work reported in the chatlog, see the [stage intro](../cases/Stage%20intro.md) and [FOXTALE](../cases/FOXTALE.md) cases; their original media is not in this repository.
