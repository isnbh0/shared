# The comparison runs

The runs here are records of the attempt, each kept with its conditions, its observations, and the findings it produced, negative ones included. The making of SLASH_MY superseded the series.

The runs looked into the gap between a treatment a viewer can recognize and a production that convinces. Keep each condition and each negative finding attached to its result. Every run was built before work on SLASH_MY began on 2026-10-01.

## Snapshot and availability

This page reads the run records at `32dec413`, inspected on 2026-10-02 in John's workspace, where the comparison lab keeps each run with its run notes, source, and previews. Full videos and some detailed stills stay there as workspace media, and the run notes record the observations in text and in stills kept with them. This page is a reading of those records: the observations below come from them, and the craft connections proposed beside them are interpretations.

## Use the series to ask better questions

If a component is weak, compare a change whose visible or audible effect you can name. Hold enough context fixed to interpret the result, and keep in mind that isolated excerpts can miss setup and payoff. [Focused comparison](../patterns/Focused%20comparison.md) gives a structure for the inspection, and [typographic events](../knowledge/Typographic%20events.md) shows which relationships inside one event are worth examining.

D-008's run notes plan one judgment per pair over 720p excerpts. John's answers sit in a local response file, the last saved on 2026-10-01.
