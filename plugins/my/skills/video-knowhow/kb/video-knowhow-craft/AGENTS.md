# Video know-how: craft (agent guide)

- **Shelves**: this folder is the craft shelf of the video know-how package. Its sibling is the code shelf, [Video know-how: code](../video-knowhow-code/Home.md).
- **Entry**: [Home](Home.md). Its routes lead into [the code shelf](../video-knowhow-code/Home.md) and into curated summaries of John's motion and design reference collections, which stay in the workspace.
- **Conventions**: read [Editorial notes](Editorial%20notes.md) before writing a page. It sets page roles, the evidence distinctions and their code shelf equivalents, page format and links, and maintenance. [Integration ownership](Integration.md) names the page that owns each shared subject: update that page once and link to it. Terms are in the [Glossary](../video-knowhow-code/Glossary.md). Edit them in `../video-knowhow-code/glossary.toml`, render with `uv run tools/glossary.py`, and check prose with `uv run tools/termcheck.py`.
- **Ledgers**: this shelf cites the code shelf's [audio source ledger](../video-knowhow-code/sources/Audio%20sources.md), [chatlog index](../video-knowhow-code/sources/Chatlog%20index.md), and [Soundtrack code case](../video-knowhow-code/cases/Soundtrack%20code.md). Put external audio claims in the audio source ledger.
- **Link check**: from this folder, run `uv run tools/linkcheck.py`. `uv run tools/package.py --dry-run` runs the link and term checks on a fresh copy of the last commit; `uv run tools/package.py OUT_DIR` builds the zip package.
- **Skill sync**: `uv run tools/sync_skill.py DEST` rebuilds the package and replaces the contents of DEST, the `kb/` folder of a skill that bundles the package, with it; DEST's parent must hold SKILL.md.
- **Reference collections**: the motion reference (a generated mirror of [Awesome AI Motion](https://github.com/gongnyang/awesome-ai-motion) at a recorded upstream snapshot) and the design collection stay in John's workspace. Do not link into them. Where a page relies on a catalog card, inline the relied-on claim and name the collection.
- **Generated**: the HTML pages in `roundup/`, whose glossary items link into the package Glossary. Edit the roundup Markdown, then run `uv run roundup/render_static.py` to rebuild both HTML pages from it and glossary.toml.
- **Provenance**: case pages name their sources in prose: which production, which snapshot date, inspected in John's workspace. SLASH_MY's picture snapshot is `32dec413` (2026-10-02) and its audio snapshots are `fd543f2a` and `f7f9d199`; the AX DAY reconstruction's snapshot is `e5ae340d`. The hashes identify versions in that workspace and resolve only there.
