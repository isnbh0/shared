# Study production cases

Start with the question a case can answer and the evidence that exists for it. Recorded source explains how something was built, a contact sheet shows selected frames, playback and listening show timing and sound, and human feedback gives a judgment made by particular people at a particular time.

## Follow a case across scopes

- [Jitter to repair](../cases/Jitter%20to%20repair.md): time sampling → instability → mechanism → recurring fix → emotional progression → implementation and review.
- [Page to larger context](../cases/Page%20to%20larger%20context.md): geometry → camera → containment → continuity → sequence contrast → implementation and review.
- [Anticipation to title](../cases/Anticipation%20to%20title.md): glyph targets → assembly → result → build and rest → setup/payoff → implementation and review.

Read any path in reverse to start from direction and work down to controls. An adaptation of a concept is labeled as a proposal, and a linked implementation demonstrates only the case it implements.
