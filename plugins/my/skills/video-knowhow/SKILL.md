# Video know-how

The `kb/` folder beside this file is one person's practice notes on making video with code, in two
linked shelves: a craft shelf (motion, scenes, sequences, whole-piece direction, sound production)
and a code shelf (representations, reusable operations, audio technique, capture and delivery). It
also holds a starter, a runnable showcase, samples, source ledgers, and a glossary.

## Where to enter

Read `kb/README.md` and `kb/AGENTS.md` first. They describe what the notes rely on, route you to the
right shelf and page, and set the writing rules for each shelf. Follow their routing; this file does
not repeat it.

## Starting a production

The starter is `kb/video-knowhow-code/starter/` and the showcase, a fuller example built on the
starter, is `kb/video-knowhow-code/showcase/`. Copy one of them out of the skill into the workspace
before editing, then run `npm install` and follow its README there. The showcase loads code from
`samples/`, so copy `kb/video-knowhow-code/samples/` too and keep it beside the showcase folder.
Leave the copies inside the skill unchanged.

## The kb is generated

The kb is a generated copy of the package, rebuilt from its source repository. Changes made here are
overwritten on the next rebuild; propose them at the source instead.
