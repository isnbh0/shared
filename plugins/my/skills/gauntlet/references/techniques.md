# Gauntlet techniques

Use whichever of these fit the question. They combine freely.

## Shaping pairs

- **One change per pair.** Change exactly one thing against a base, so a choice can be
  attributed to it.
- **Package check.** Show a bundle of changes against a base, to see whether they hold up
  together. A tie doesn't say which part overshot, so look at whether the split follows excerpt,
  theme or what's in view.
- **Excerpt edges.** Check each excerpt's edges for lead-ins cut mid-thought, oversized media,
  and context the frame hides that the full artifact would show.
- **Coverage.** Show a variable on more than one excerpt, and in every theme or mode the artifact
  has. Check the coverage that was actually built, not what was planned.

## Checking the data

- **Null pairs.** Both sides are identical, and any A or B answer is noise. A few per page is
  usually enough. In flip mode a null is easy to spot, because nothing moves on Space, so a
  perfect null score shows attention more than precision. A near-null with a tiny real difference
  tests more.
- **Swapped repeats.** Repeat an earlier pair with the sides swapped, far enough back that the
  first answer isn't fresh in memory. A flip means that preference isn't stable at that size of
  difference. A repeat in a later sitting tests more than one on the same page.
- **Balanced sides.** Spread the variant about evenly across A and B, with a reproducible draw, so
  a side bias can't pass for a preference.
- **Order.** Avoid neighbouring pairs from the same excerpt where you can.
- **Read time and swaps.** Long times and many swaps mark hard calls. A single very long time is
  usually an interruption.

## Finding edges

- **Adaptive bisection.** Start each search at an obviously bad value. Then halve the gap between
  the furthest value that held and the nearest that lost, until the gap is under the set step.
  Finish with a swapped confirm of the nearest losing value. The adaptive template does all of
  this.
  - Each step rests on a single forced choice, so an edge is accurate to about one step.
    Instability, when it shows, shows at the smallest steps.
  - Search both directions of a variable on the same excerpt, or its floor and ceiling will
    reflect different content.
  - The bad probes come first, so late pairs carry the close calls. Keep adaptive pages short,
    or split them across sittings.
