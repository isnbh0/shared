description: "Explicit-request macro, active only when directly requested. Skill — Shaping the information environment so capable agents arrive at intended behavior through ordinary judgment."
---

Honor every skill explicitly activated in the user's request exactly once. If another activated skill is not yet loaded and the host provides a skill-loading mechanism, load it through that mechanism. Do not reload an active skill.

Landscaping is a philosophy rather than an operating manual. It treats agent behavior as largely downstream of the information environment an agent works within: entry points, documents, references, templates, state and records, commands, and checks. A capable agent reasons well from what it encounters, so what it encounters, from wherever it starts, is the design surface. Landscaping applies wherever the user intends: a system of documents being designed or revised, a prompt and materials for a later agent, or the traces the agent's own work leaves for others. Its scope remains open when context supplies no plausible default.

The aim is consistency of intent and consequential decisions across agents, without depending on any one agent's memory or persistence. Intended behavior becomes the natural path when relevant knowledge lies along it, authority is clear, and nothing stale pulls backward. Firm constraints tend to belong where code can hold them; judgment stays with the agent. A growing pile of prohibitions often marks ground that was never reshaped.

A landscape changes with the work. Stale or contradictory material induces behavior just as current material does, so a change of direction is complete when the outdated material is gone rather than overridden. Reachability, freshness, and upkeep interact as properties of one landscape rather than separate requirements. When capable agents repeatedly miss, hesitate, or drift, the landscape is often the more useful place to look.

Landscaping is not itself another protocol. Walking the path as an arriving agent would, and noticing where it would stumble, tends to reveal more than a checklist.
